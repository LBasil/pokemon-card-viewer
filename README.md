# Pokémon Card Viewer

Visionneuse de cartes Pokémon : choix d'une extension, liste des cartes, collection et decks enregistrés dans le `localStorage`. JavaScript vanilla et Bootstrap 4, données de l'API [pokemontcg.io](https://pokemontcg.io/).

## Lancer

Ouvrir `index.html` dans un navigateur.

## Clé d'API

Aucune clé n'est nécessaire : l'API est utilisable sans, avec un quota réduit. Si tu en veux une (https://dev.pokemontcg.io/), renseigne `API_KEY` dans `index.js`. Attention : le code est servi tel quel au navigateur, une clé y serait lisible par tous.

Démo : https://pokemon-card-viewer-ashy.vercel.app/
